Regras Anti-Bloqueio

Como escrever mensagens variadas (spintax)

Use chaves com opções separadas por | para que cada destinatário receba uma variação com o mesmo sentido:

{Oi|Olá|E aí}, tudo bem? {Temos|Preparamos} uma novidade para você.

Boas práticas para não ser bloqueado

  • Evite disparar a mesma mensagem, idêntica, para muitos contatos em pouco tempo.
  • Prefira lotes menores (até ~50 números) espaçados ao longo do dia.
  • Números novos devem "esquentar" gradualmente — comece com poucos envios por dia.
  • Evite links encurtados ou conteúdo repetitivo que pareça spam.
  • Para alto volume com garantia de entrega, prefira a API Oficial (Cloud API).
